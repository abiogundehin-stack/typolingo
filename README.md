TypeLingo 🦉⌨️

TypeLingo is a Duolingo-style touch-typing trainer designed to help you build typing speed and accuracy through bite-sized lessons, character coaches, daily quests, and timed milestone challenges.

✨ Features

Winding Learning Path & Guidebooks: Progress through units starting from home-row basics (F and J) up to top/bottom reaches, capitals, numbers, and code syntax—complete with unit Guidebooks for finger placement tips.

Timed Milestone Challenges (Every 5 or 10 Steps): Configurable in Settings (Every 5th Step or Every 10th Step) to launch Ramp Up / Match Madness timed word sprints based on the unit you are practicing.

Character Coaches: Get live typing tips, streak cheers, and feedback from Pip the Owl, Zara, Coach Max, Bea, and Professor Eddy (choose a favorite in Profile or Settings, or let them rotate).

Interactive On-Screen Keyboard: Highlights the next key and optional finger-zone colors as you type, paired with live WPM and Accuracy tracking.

Full Duolingo-Style Tabs: Includes Learn, Practice Hub (Mistake Review & Rapid Word Sprint), Leaderboards (Diamond League), Quests, Shop (Heart Refill, Streak Freeze, 2X XP Boost), Profile, and Settings.

🚀 How to Run

Download or clone the repository.

Open index.html in any modern web browser.

Click any unlocked node on the path, tap inside the typing box, and start typing!

🛠️ Built With

HTML, CSS (Tailwind CSS), and Vanilla JavaScript

Web Audio API for subtle key taps, chimes, and celebration sounds

localStorage for saving your XP, streaks, gems, and settings
